# FareSlip "Stop and ask" list (example)

- Anything touching prod or real users' data (deleting or migrating records, emails to real
  people).
- A change to signed-off behaviour (meal cap, approval levels, retention, ...).
- Rules waiting on Finance (tips, cash).
- A new paid AWS service or a clear rise in running cost.
- A security or tenant finding the checker raises that cannot be settled in code.
